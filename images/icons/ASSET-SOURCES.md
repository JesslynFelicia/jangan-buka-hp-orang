# App icon image sources

Retrieved 2026-11-02 from official Apple-hosted pages and image CDNs. These are existing app icon image files downloaded from the internet, with no local redrawing or recoloring.

The App Store lookup API supplied each artwork URL: https://itunes.apple.com/lookup?country=us&id=1584215428,1146562112,1110145109,1232058109,1108185179,1584216193,1069512615,1108187390,310633997,389801252,333903271

Settings comes from the inline Settings app icon in the official iPhone User Guide. It is 60 x 60 pixels; the twelve App Store images are 512 x 512 pixels. The thirteen image files total 322,683 bytes. JPEG/PNG signatures and image decoding were checked locally. YouTube was retrieved from https://itunes.apple.com/lookup?id=544007664&country=us.

The Calendar artwork is the publisher's static App Store icon and displays Tue 1. It does not represent the fictional phone's current date. The App Store images reflect the publishers' current artwork at retrieval, including glossy styling on several icons.
